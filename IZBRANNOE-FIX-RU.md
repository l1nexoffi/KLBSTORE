# Исправление избранного KLB STORE

1. Сделай резервную копию Supabase.
2. Выполни `marketplace-favorites-fix.sql` в Supabase → SQL Editor.
3. Замени файлы сайта содержимым папки `klb_full` в GitHub Pages.
4. Сохрани действующий `supabase-config.js` (не заменяй его примером).
5. После публикации открой сайт и обнови страницу без кэша: Ctrl+F5.

Что изменилось:
- Незарегистрированному посетителю при нажатии на сердечко открывается форма регистрации; запись в избранное не создаётся.
- Для текущего маркетплейса избранное хранится отдельно в `seller_listing_favorites`, так как старое `favorites` связано с таблицей `products`, а витрина использует `seller_listings`.
- При следующем входе прежние локальные избранные товары переносятся в новую таблицу, если их ID существуют в `seller_listings`.
- Окно «Избранное» загружает реальные карточки товаров из Supabase; можно убрать товар или перейти к покупке.
- Ссылка «Админ-панель» в футере скрыта у гостей и обычных пользователей; она видна только администратору и модераторам. Доступ к админке по прямому URL по-прежнему отдельно проверяется серверной сессией.

Существующие таблицы, товары, заказы и балансы не удаляются. SQL нужно выполнить один раз; повторный запуск безопасен.
