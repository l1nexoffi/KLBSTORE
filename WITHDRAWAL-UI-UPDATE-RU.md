# KLB STORE — обновление выбора вывода средств

## Что изменилось
- Убраны нативные системные выпадающие списки браузера.
- Добавлены собственные карточки способов вывода: «На карту банка», «Перевод по СБП», «USDT TRC20».
- Список банков открывается внутри сайта: брендированные значки, аккуратное название, поиск и отметка выбранного банка.
- Существующие поля реквизитов, проверка телефона/адреса и минимальная сумма 500 ₽ сохранены.
- Способ СБП записывается в Supabase как `sbp_phone` и отображается в админке как «Перевод по СБП».
- На телефонах список банков имеет собственную прокрутку и не вызывает системное меню select.

## Установка
1. Сделайте резервную копию базы Supabase.
2. В Supabase SQL Editor выполните `withdrawal-sbp-method-migration.sql`. Миграция сохраняет существующие заявки и балансы; её можно запускать повторно.
3. Замените файлы сайта содержимым папки `klb_full` из архива.
4. Сохраните действующий `supabase-config.js` — не заменяйте его примером.
5. Дождитесь публикации GitHub Pages и откройте сайт с жёстким обновлением (`Ctrl+F5`).

## Проверка
- Выберите «На карту банка», выберите банк и отправьте тестовую заявку.
- Повторите с «Перевод по СБП». В админке способ должен отображаться как «Перевод по СБП».
- Проверьте USDT TRC20: поле банка должно скрываться, появляться поле адреса, а способ в админке — «USDT TRC20».
- Для всех трёх способов минимальная сумма остаётся 500 ₽.

## Без изменений
Пополнение баланса, чаты, Telegram, жалобы, промокоды, модераторы, избранное и Escrow не изменяются. Новые Edge Functions и секреты не требуются.
