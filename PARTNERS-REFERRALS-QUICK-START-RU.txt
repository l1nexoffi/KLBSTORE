KLB STORE — ПАРТНЁРЫ И РЕФЕРАЛЬНЫЕ ПРОМОКОДЫ

ЧТО ДОБАВЛЕНО
1. Админ-панель → Партнёры:
   - назначение партнёра по логину пользователя;
   - тип партнёра: YouTuber, стример, блогер, инфлюенсер, автор контента, другое;
   - включение/отключение партнёрского статуса;
   - сводная статистика по промокоду, завершённым заказам, обороту, доходу и долгу.
2. Админ-панель → Промокоды:
   - отдельная форма создания реферального промокода;
   - логин партнёра, название, код, скидка покупателю, комиссия партнёру, дата окончания;
   - изменение условий и отключение/включение кода;
   - одновременно может быть только один активный реферальный код на партнёра.
3. Профиль партнёра:
   - кнопка «Для партнёров» появляется после назначения роли;
   - показ промокода, скидки покупателю и процента партнёра;
   - количество использований, завершённые заказы, число покупателей, сумма покупок и заработок.
4. Комиссия:
   - скидка покупателя применяется к цене товара на этапе оплаты;
   - комиссия партнёра считается от исходной суммы заказа ДО скидки (как в примере 1 000 ₽, скидка 5%, комиссия 5% = 50 ₽ партнёру);
   - деньги начисляются партнёру только после подтверждения покупателем получения товара/услуги;
   - при одобренном споре уже начисленная комиссия сторнируется; если доступного баланса не хватает, остаток попадает в долг и погашается из будущих партнёрских комиссий.

УСТАНОВКА
1. Сделайте резервную копию Supabase.
2. Убедитесь, что ранее применены миграции:
   - wallet-marketplace-migration.sql;
   - marketplace-escrow-chat.sql;
   - klb-account-staff-telegram.sql;
   - marketplace-promo-redemption.sql;
   - marketplace-trust-safety.sql;
   - marketplace-categories-promotions.sql (если используете обновлённый каталог).
3. Откройте Supabase → SQL Editor → New query.
4. Откройте marketplace-referral-partners.sql в Блокноте, скопируйте весь текст, вставьте в SQL Editor и нажмите Run.
5. Распакуйте ZIP сайта и загрузите содержимое папки klb_full в корень GitHub Pages с заменой файлов.
6. Сохраните действующий supabase-config.js — не перезаписывайте его примером.
7. Дождитесь публикации GitHub Pages и обновите браузер Ctrl+F5.

ПОРЯДОК НАСТРОЙКИ
1. В админке откройте «Партнёры» и назначьте пользователя по его логину.
2. Откройте «Промокоды» и создайте реферальный код для назначенного партнёра.
3. Партнёр обновляет профиль и открывает «Для партнёров».
4. Покупатель активирует код в своём профиле, затем оплачивает заказ.
5. После завершения услуги/передачи товара продавцом и подтверждения покупателем партнёрская комиссия начисляется на баланс.

ВАЖНО
- Типы партнёра — это отметки/категории, финансовые правила для них одинаковы.
- Комиссия рассчитывается от суммы до скидки, а скидка уменьшается из суммы, которую платит покупатель. Партнёрская комиссия выплачивается отдельно из средств площадки.
- Не запускайте повторно старые большие SQL-миграции. Для этого обновления нужен только marketplace-referral-partners.sql.
- Тестируйте сначала на двух тестовых аккаунтах и небольших суммах: активация кода → покупка → подтверждение продавца → подтверждение покупателя → проверка баланса партнёра.
- SQL в реальном Supabase не запускался автоматически. Его необходимо применить в своём проекте.
