# Активация промокодов покупателями — KLB STORE

## Что добавлено
- В профиле появилась кнопка «Активировать промокод».
- Пользователь может держать один активный промокод на аккаунт.
- Код проверяется на активность, срок действия и глобальный лимит применений.
- Один промокод можно использовать один раз на аккаунт.
- После успешной покупки код автоматически расходуется. При ошибке оплаты код остаётся активным.
- Скидка применяется к сумме заказа до комиссии сервиса. Комиссия 5% рассчитывается от фактически оплаченной суммы, поэтому скидка уменьшает базу расчёта выплаты продавцу и комиссии.

## Установка
1. Сделайте резервную копию Supabase.
2. Убедитесь, что ранее выполнены `marketplace-escrow-chat.sql` и `klb-account-staff-telegram.sql` (они создают заказы, кошельки и `marketplace_promo_codes`).
3. Выполните `marketplace-promo-redemption.sql` в Supabase → SQL Editor → Run.
4. Опубликуйте файлы из папки `klb_full` в корень GitHub Pages. Не заменяйте свой `supabase-config.js`.
5. Перезагрузите сайт через Ctrl+F5. SQL повторно запускать не нужно после успешного выполнения.

## Как использовать
1. Пользователь открывает профиль → «Активировать промокод».
2. Вводит код, созданный администратором в админке → «Промокоды».
3. После успешной активации видит код и размер скидки в профиле.
4. При следующей покупке скидка показывается в окне оплаты и применяется сервером в транзакции.
5. После успешной покупки промокод автоматически снимается и помечается использованным.

Применение промокода исключительно серверное: клиент не может сам назначить скидку или изменить итоговую стоимость. Прямая запись в таблицы промокодов из клиентского кода не используется.
