# KLB STORE — категории, подкатегории и платное продвижение

## Что добавлено

- Главная витрина показывает сначала объявления KLB STORE, затем объявления продавцов, отсортированные по рейтингу продавца, числу отзывов и цене.
- Категории верхнего уровня: Fortnite, Steam, Roblox, Claude, GTA VI, PlayStation, ChatGPT, Telegram, Brawl Stars, TikTok и Другое.
- У каждой верхней категории собственные подкатегории. Примеры: Fortnite → Аккаунты / Подарки / Наборы / Боевой пропуск / Буст / Услуги / Предметы / Twitch Drops; Claude → Услуги / Аккаунты / Подписки / Чистые аккаунты.
- При создании и редактировании объявления продавец выбирает категорию и подкатегорию. Старое поле `category` сохраняется для совместимости с логикой заказа и подтверждения получения.
- В панели продавца для активного объявления есть кнопка «Продвинуть за 49 ₽».
- Продвижение оплачивается с доступного баланса серверной RPC-функцией. Прямое изменение баланса из браузера не используется.

## Правила продвижения

- Стоимость одного продвижения — 49 ₽.
- В течение первых трёх дней продвинутый товар занимает верхнюю позицию категории.
- Если другой продавец продвигает товар в этой категории, более новое продвижение становится первым, предыдущее сдвигается на следующую позицию.
- После трёх дней позиция продвижения автоматически снижается на одну позицию за каждый следующий день.
- Освобождаемые места заполняются обычными объявлениями. Обычная выдача сортируется по среднему рейтингу продавца, числу отзывов, затем по возрастанию цены.
- Очереди продвижения независимы для каждой категории.

## Установка

1. Сделайте резервную копию проекта Supabase.
2. Убедитесь, что уже установлены миграции `marketplace-escrow-chat.sql` и `marketplace-trust-safety.sql` (в частности, таблица `marketplace_reviews`).
3. В Supabase → SQL Editor выполните `marketplace-categories-promotions.sql` от имени владельца проекта / postgres.
4. Загрузите содержимое папки `klb_full` в корень GitHub Pages, заменив совпадающие файлы.
5. Сохраните текущий `supabase-config.js` — его перезаписывать не нужно.
6. Дождитесь публикации и обновите сайт через Ctrl+F5.

Существующие объявления не удаляются. Миграция пытается распознать root-категорию по словам в названии/описании. Неопределённые объявления остаются в категории «Другое» и могут быть переклассифицированы продавцом при редактировании.

## Проверка

- Убедиться, что главная витрина показывает товары KLB STORE первыми.
- Открыть Fortnite, затем Аккаунты — должны отображаться только объявления Fortnite / Аккаунты.
- Проверить подкатегории Claude и Steam.
- На тестовом аккаунте продавца с балансом от 49 ₽ продвинуть активное объявление.
- Проверить, что списалось ровно 49 ₽ и появилась запись `promotion` в `wallet_ledger`.
- Продвинуть другое объявление в той же категории: новое должно стать первым, предыдущее — следующим.
- Продвинуть объявление в другой категории: очередь первой категории не должна измениться.
- Проверить, что обычные объявления ранжируются по рейтингу, числу отзывов и цене.

## Примечания

- Продвигать можно только собственное, одобренное и активное объявление с остатком товара.
- Для продвижения нужен доступный баланс не менее 49 ₽.
- KLB STORE выделяется на главной витрине отдельно; платное продвижение продавцов применяется на страницах категорий.
- SQL не меняет роли пользователей, балансы существующих кошельков и данные сделок, кроме списания 49 ₽ при реальном вызове функции продвижения.
