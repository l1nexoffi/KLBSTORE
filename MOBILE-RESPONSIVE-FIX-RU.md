# KLB STORE — исправление мобильной версии

Обновление исправляет мобильное позиционирование модальных окон, экран входа/регистрации и уплотняет шапку/каталог на узких экранах.

## Установка
1. Сделайте резервную копию текущего репозитория.
2. Загрузите обновлённые frontend-файлы из `klb_full` в корень GitHub Pages с заменой старых файлов.
3. Сохраните ваш действующий `supabase-config.js` — в этом архиве он намеренно не включён.
4. Supabase SQL и Edge Functions повторно запускать/разворачивать не требуется: этот патч касается адаптивной вёрстки и поведения модальных окон.
5. После публикации откройте сайт и выполните полную перезагрузку браузера.

## Главный технический фикс
Ранее `body` анимировался через `transform: translateY(0)`. CSS transform на `body` менял containing block для `position: fixed`, поэтому модальное окно привязки/авторизации могло оказываться внизу длинной страницы. Анимация `body` заменена на opacity-only, а модальные окна позиционируются по Visual Viewport с учётом экранной клавиатуры и safe area.
