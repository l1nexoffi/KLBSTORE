# KLB STORE — starter

Static prototype for GitHub Pages. This is a visual front-end only; sample products and buttons are demo content.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `klb-store`).
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, and save.
6. Wait for the Pages URL to appear.
